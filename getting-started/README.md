# Getting started

Set up PN532Killer over USB, learn how its three working modes differ, and update the firmware safely.

## Recommended order

1. Read the [product overview](overview.md) and check [compatibility](../reference/compatibility.md).
2. Identify the [hardware and controls](hardware-and-controls.md) on your device.
3. Install the [PN532 CLI](../software/python-cli.md), connect with `hw connect`, and complete the [quickstart](quickstart.md).
4. Review [working modes](working-modes.md) before enabling Emulator or Sniffer mode.
5. Update the [firmware](firmware-update.md) only when a required feature or fix is newer than your installed build.

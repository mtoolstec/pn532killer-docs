# Troubleshooting

Start with the symptom below.

| Symptom | Go to |
| --- | --- |
| No serial/COM port | [Device not detected](device-not-detected.md) |
| Software sees a port but cannot connect | [Device not detected](device-not-detected.md#the-port-exists-but-connection-fails) |
| Screen shows `Device Unauthorized` | [Device Unauthorized](device-unauthorized.md) |
| Update stopped or board no longer starts normally | [Firmware recovery](firmware-recovery.md) |
| BLE is visible but apps cannot communicate | [Bluetooth extension](../guides/bluetooth-extension.md#connection-tips) |
| Emulation is not recognized | [Emulator troubleshooting](../guides/emulator-mode.md#troubleshooting-an-emulation) |

## Information to collect

Before requesting support, record:

- Main-board and extension hardware revision
- Firmware filename or reported version
- Operating system and application version
- USB or BLE host interface
- Serial port name and baud rate
- Exact error message
- Steps that reproduce the problem

Do not post tag dumps, recovered keys, private identifiers, or access-system data in a public issue.

# Reader and emulator

Use Reader mode for supported tag identification, reading, and writing. Use Emulator mode to present a compatible profile stored in one of the device slots.

- [Reader mode](reader-mode.md)
- [MIFARE Classic recovery](mifare-classic-recovery.md)
- [Emulator mode](emulator-mode.md)
- [Upload and download dumps](upload-download-dumps.md)
- [Bluetooth extension](bluetooth-extension.md)

Always read and back up a tag or slot before writing. Confirm the selected protocol and profile before enabling emulation.
